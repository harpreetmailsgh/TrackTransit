DATA APPROACH — IMPORTANT:
We are using GTFS static + GTFS-RT real-time feeds. NOT the GO Transit API. NO mock data.

GTFS Static file (schedules, stops, routes, platforms):
https://www.gotransit.com/static_files/gotransit/assets/Files/GO_GTFS.zip
- No registration needed, download directly
- Already downloaded and saved in the project folder

GTFS-RT live feeds (no key needed, free, public):
- Trip updates (delays):     https://api.gotrains.ca/gtfsrt/v2/GO/GTFSRt/TripUpdates
- Vehicle positions:         https://api.gotrains.ca/gtfsrt/v2/GO/GTFSRt/VehiclePosition
